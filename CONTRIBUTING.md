# Contributing to Airwaves

First off, thank you for considering contributing to **Airwaves**! 📻

## 🎵 Suggesting / Adding New Stations

We love community suggestions for independent radio streams, soundscape generators, and ambient audio projects.

### Station Criteria
1. **Independent & Unique**: Must be an independent radio station, artist broadcast, soundscape, or curated stream.
2. **Accessible**: Live stream, embeddable YouTube stream, or accessible web player.
3. **No Intrusive Ads / Paywalls**: Must be freely listenable without aggressive unskippable ads.
4. **Creator Attribution**: You must provide the creator's name and original project link.

### How to Submit
- **Via the UI**: Use the **"Suggest a Station"** button directly on the live website.
- **Via GitHub**: Open an [Issue](https://github.com/SubhamPro11/airwaves/issues) or submit a Pull Request.

---

## 💻 Development Workflow

1. **Fork and clone the repo**:
   ```bash
   git clone https://github.com/SubhamPro11/airwaves.git
   cd airwaves
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the local dev server**:
   ```bash
   npm run dev
   ```

4. **Verify TypeScript & Build**:
   ```bash
   npm run build
   ```

---

## 🎨 UI Guidelines & Philosophy
- **Dark Theme First**: Amber / orange neon accents (`#f59e0b` / `#fbbf24`), deep background (`#0a0e14`).
- **Performance & Privacy**: No client tracking, fast load times, responsive across mobile, tablet, and desktop.
- **No Clutter**: Keep UI intuitive, distraction-free, and focus on the listening experience.
